Computer science లో **priority queue** అనేది ఒక abstract data type — ఇది మామూలు queue లేదా stack
data structure లాంటిదే, కానీ అదనంగా ప్రతి element కి ఒక "priority" (ప్రాధాన్యత) ఉంటుంది. Priority
queue లో, ఎక్కువ priority ఉన్న element ని తక్కువ priority ఉన్న element కంటే ముందు serve చేస్తారు.
రెండు elements కి ఒకే priority ఉంటే, queue లో వాటి order ప్రకారం serve చేస్తారు.

Priority queues ని ఎక్కువగా heaps తో implement చేస్తారు కానీ, concept పరంగా అవి heaps కంటే వేరు.
Priority queue అనేది "list" లేదా "map" లాంటి ఒక abstract concept; ఒక list ని linked list తో గానీ array
తో గానీ implement చేయొచ్చు, అలాగే priority queue ని heap తో గానీ, unordered array లాంటి వేరే చాలా
పద్ధతులతో గానీ implement చేయొచ్చు.
