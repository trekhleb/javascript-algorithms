# Playground

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

Data structures, algorithms తో ఆడుకోవడానికి `playground.js` file వాడొచ్చు. `playground.js` లో
రాసిన code ని `./__test__/playground.test.js` file లో test చేయొచ్చు.

Tests రన్ చేయడానికి ఇది రన్ చేస్తే చాలు:

```
npm test -- -t 'playground'
```
