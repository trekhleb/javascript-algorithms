# Longest Common Substring Problem

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

Longest common substring problem అంటే — రెండు లేదా అంతకంటే ఎక్కువ strings లో substring గా ఉండే
అతి పొడవైన string (లేదా strings) కనుక్కోవడం.

## Example

`ABABC`, `BABCA`, `ABCBA` strings యొక్క longest common substring `ABC`, దాని పొడవు 3. మిగతా common
substrings `A`, `AB`, `B`, `BA`, `BC`, `C`.

```
ABABC
  |||
 BABCA
  |||
  ABCBA
```
