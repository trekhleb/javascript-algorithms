# Palindrome Check

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

[Palindrome](https://en.wikipedia.org/wiki/Palindrome) అంటే ముందు నుంచి చదివినా, వెనక నుంచి చదివినా
ఒకేలా ఉండే string. అంటే string రెండో సగం, మొదటి సగాన్ని తిరగేస్తే వచ్చేదే.

## Examples

ఇవి palindromes (కాబట్టి `TRUE` return చేస్తాయి):

```
- "a"
- "pop"     ->  p + o + p
- "deed"    ->  de + ed
- "kayak"   ->  ka + y + ak
- "racecar" ->  rac + e + car
```

ఇవి palindromes కావు (కాబట్టి `FALSE` return చేస్తాయి):

```
- "rad"
- "dodo"
- "polo"
```
