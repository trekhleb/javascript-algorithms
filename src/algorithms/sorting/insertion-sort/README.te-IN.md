# Insertion Sort

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md),
[_Português_](README.pt-BR.md)

Insertion sort అనేది ఒక సింపుల్ sorting algorithm — చివరి sorted array (లేదా list) ని ఒక్కో item
కలుపుతూ కడుతుంది. పెద్ద lists మీద quicksort, heapsort, లేదా merge sort లాంటి advanced algorithms
తో పోలిస్తే ఇది చాలా slow.
