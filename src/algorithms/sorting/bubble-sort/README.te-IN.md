# Bubble Sort

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md),
[_Português_](README.pt-BR.md)

Bubble sort (దీన్ని కొన్నిసార్లు sinking sort అని కూడా అంటారు) అనేది ఒక సింపుల్ sorting
algorithm. ఇది sort చేయాల్సిన list మీద మళ్ళీ మళ్ళీ వెళ్తూ, పక్కపక్కన ఉన్న ప్రతి జత items ని
compare చేసి, అవి తప్పు order లో (ascending లేదా descending వరుసలో) ఉంటే వాటిని మార్చేస్తుంది
(swap చేస్తుంది). ఒక్క swap కూడా అవసరం లేనంత వరకు list మీద ఇలా వెళ్తూనే ఉంటుంది — swaps
అవసరం లేదంటే list sort అయిపోయింది అని అర్థం.
