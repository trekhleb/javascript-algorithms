# Cartesian Product

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

Set theory లో Cartesian product అనేది చాలా sets నుంచి ఒక set (దీన్నే product set లేదా సింపుల్ గా
product అంటారు) ఇచ్చే ఒక mathematical operation. అంటే, A, B అనే sets కి, Cartesian product A × B
అంటే a ∈ A, b ∈ B అయ్యే అన్ని ordered pairs (a, b) ఉన్న set.

`A={x,y,z}`, `B={1,2,3}` అనే రెండు sets యొక్క Cartesian product `AxB`
