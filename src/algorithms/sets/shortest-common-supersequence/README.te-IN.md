# Shortest Common Supersequence

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

`X`, `Y` అనే రెండు sequences యొక్క shortest common supersequence (SCS) అంటే — `X`, `Y` రెండూ
subsequences గా ఉండే అతి చిన్న sequence.

ఇంకోలా చెప్పాలంటే, str1, str2 అనే రెండు strings ఇస్తే — str1, str2 రెండూ subsequences గా ఉండే
అతి చిన్న string కనుక్కోవాలి.

ఈ problem కి longest common subsequence problem కి దగ్గరి సంబంధం ఉంది.

## Example

```
Input:   str1 = "geek",  str2 = "eke"
Output: "geeke"

Input:   str1 = "AGGTAB",  str2 = "GXTXAYB"
Output:  "AGXGTXAYB"
```
