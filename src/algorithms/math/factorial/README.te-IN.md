# Factorial

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md), [_简体中文_](README.zh-CN.md), [_Français_](README.fr-FR.md), [_Türkçe_](README.tr-TR.md), [_ქართული_](README.ka-GE.md), [_Українська_](README.uk-UA.md).

Mathematics లో, negative కాని integer `n` యొక్క factorial ని `n!` అని రాస్తారు. అంటే `n` కంటే
తక్కువ లేదా సమానంగా ఉన్న అన్ని positive integers ని గుణిస్తే వచ్చేది. ఉదాహరణకి:

```
5! = 5 * 4 * 3 * 2 * 1 = 120
```
