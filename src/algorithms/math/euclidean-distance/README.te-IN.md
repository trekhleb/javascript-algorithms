# Euclidean Distance

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

Mathematics లో, Euclidean space లో రెండు points మధ్య **Euclidean distance** అంటే ఆ రెండు points ని కలిపే line segment పొడవు. Points యొక్క Cartesian coordinates నుంచి Pythagorean theorem వాడి దీన్ని లెక్కపెట్టొచ్చు, అందుకే దీన్ని కొన్నిసార్లు Pythagorean distance అని కూడా అంటారు.

![Euclidean distance between two points](https://upload.wikimedia.org/wikipedia/commons/5/55/Euclidean_distance_2d.svg)

## Distance formulas

### One dimension

Real line మీద ఏవైనా రెండు points మధ్య దూరం అంటే, వాటి coordinates తేడా యొక్క absolute value
