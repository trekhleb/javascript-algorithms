# Radian

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

**Radian** (symbol **rad**) అనేది angles ని కొలిచే unit. Mathematics లో చాలా రంగాల్లో angles
కొలవడానికి ఇదే standard unit.

Unit circle లో ఒక arc (వంపు) పొడవు, అది ఏర్పరిచే angle ని radians లో కొలిస్తే వచ్చే నంబర్ కి
సమానం; ఒక radian అంటే `57.3` degrees కంటే కొంచెం తక్కువ.

ఒక circle radius ఎంత పొడవు ఉందో, అంతే పొడవు ఉన్న arc ఏర్పరిచే angle `1 radian`. మొత్తం
చుట్టుకొలత ఏర్పరిచే angle `2π radians`.

![Radian](https://upload.wikimedia.org/wikipedia/commons/4/4e/Circle_radians.gif)

ఒక పూర్తి రౌండ్ అంటే 2π radians (ఇక్కడ radius ఒకటి ఉన్న circle తో చూపించారు, కాబట్టి
చుట్టుకొలత `2π`).

![2 pi Radian](https://upload.wikimedia.org/wikipedia/commons/6/67/2pi-unrolled.gif)

**Conversions (మార్పులు)**

| Radians | Degrees |
| :-----: | :-----: |
| 0       | 0°      |
| π/12    | 15°     |
| π/6     | 30°     |
| π/4     | 45°     |
| 1       | 57.3°   |
| π/3     | 60°     |
| π/2     | 90°     |
| π       | 180°    |
| 2π      | 360°    |
