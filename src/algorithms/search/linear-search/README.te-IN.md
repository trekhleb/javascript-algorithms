# Linear Search

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md),
[_Português brasileiro_](README.pt-BR.md)

Computer science లో linear search (లేదా sequential search) అనేది ఒక list లో target value
కనుక్కునే పద్ధతి. ఇది list లో ప్రతి element ని వరుసగా చెక్ చేస్తుంది — target దొరికేదాకా, లేదా
అన్ని elements చూసేదాకా. Linear search worst case లో linear time తీసుకుంటుంది, మహా అయితే `n`
comparisons చేస్తుంది — ఇక్కడ `n` అంటే list పొడవు.

![Linear Search](https://www.tutorialspoint.com/data_structures_algorithms/images/linear_search.gif)

## Complexity

**Time Complexity**: `O(n)` - ఎందుకంటే worst case లో ప్రతి element ని సరిగ్గా ఒక్కసారి చెక్
చేస్తాం.
