# Depth-First Search (DFS)

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

Depth-first search (DFS) అనేది tree లేదా graph data structures ని traverse చేయడానికి, search
చేయడానికి వాడే algorithm. Root నుంచి మొదలుపెడతాం (graph అయితే ఏదో ఒక node ని root గా తీసుకుంటాం),
ప్రతి branch లో వీలైనంత లోతుకి వెళ్ళి, ఇక ముందుకి దారి లేనప్పుడే వెనక్కి (backtrack) వస్తాం.
