# Reversed Linked List Traversal

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md),
[_中文_](README.zh-CN.md),
[_Português_](README.pt-BR.md)

ఇచ్చిన linked list ని తిరగేసి (వెనక నుంచి ముందుకి) traverse చేయాలి.

ఉదాహరణకి, ఈ linked list తీసుకుంటే:

![](https://upload.wikimedia.org/wikipedia/commons/6/6d/Singly-linked-list.svg)

Traverse చేసే వరుస ఇలా ఉండాలి:

```text
37 → 99 → 12
```

ప్రతి node ని ఒక్కసారి మాత్రమే visit చేస్తాం కాబట్టి time complexity `O(n)`.
