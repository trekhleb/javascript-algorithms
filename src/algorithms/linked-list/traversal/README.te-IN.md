# Linked List Traversal

_వేరే భాషల్లో చదవాలంటే:_

[_Русский_](README.ru-RU.md),

ఇచ్చిన linked list ని మామూలు (ముందు నుంచి వెనక్కి) వరుసలో traverse చేయాలి.

ఉదాహరణకి, ఈ linked list తీసుకుంటే:

![Singly linked list](https://upload.wikimedia.org/wikipedia/commons/6/6d/Singly-linked-list.svg)

Traverse చేసే వరుస ఇలా ఉండాలి:

```text
12 → 99 → 37
```

ప్రతి node ని ఒక్కసారి మాత్రమే visit చేస్తాం కాబట్టి time complexity `O(n)`.
