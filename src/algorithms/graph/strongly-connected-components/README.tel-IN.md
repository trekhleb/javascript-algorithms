# Strongly Connected Component

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

ఒక directed graph లో ప్రతి జత vertices మధ్య రెండు directions లోనూ path ఉంటే, ఆ graph ని
**strongly connected** అంటారు. Graph G మొత్తం strongly connected కాకపోయినా, అందులో
`u`, `v` అనే రెండు vertices మధ్య రెండు directions లోనూ path ఉంటే, ఆ రెండు ఒకదానికొకటి
strongly connected అంటారు.
