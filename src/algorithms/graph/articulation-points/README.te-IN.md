# Articulation Points (లేదా Cut Vertices)

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

ఒక undirected connected graph లో, ఒక vertex ని (దాని గుండా వెళ్ళే edges తో సహా) తీసేస్తే
graph ముక్కలైపోతే, ఆ vertex ని articulation point (లేదా cut vertex) అంటారు.
Connected network లో ఇవి బలహీనమైన పాయింట్లు — ఇలాంటి ఒక్క పాయింట్ fail అయినా
network 2 లేదా అంతకంటే ఎక్కువ విడివిడి ముక్కలుగా విడిపోతుంది. నమ్మకంగా పనిచేసే
networks డిజైన్ చేయడానికి ఇవి ఉపయోగపడతాయి.

Disconnected undirected graph లో అయితే, ఏ vertex ని తీసేస్తే connected components సంఖ్య
పెరుగుతుందో, అదే articulation point.
