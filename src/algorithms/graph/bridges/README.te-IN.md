# Graph లో Bridges

_వేరే భాషల్లో చదవాలంటే:_
[_English_](README.md)

Graph theory లో **bridge** (దీన్నే **isthmus**, **cut-edge**, లేదా **cut arc** అని కూడా అంటారు) అంటే
graph లో ఒక edge — దాన్ని తీసేస్తే connected components సంఖ్య పెరుగుతుంది. ఇంకోలా చెప్పాలంటే,
ఒక edge ఏ cycle లోనూ లేకపోతేనే అది bridge అవుతుంది. ఒక graph లో అసలు bridges ఏమీ లేకపోతే,
దాన్ని bridgeless లేదా isthmus-free graph అంటారు.

![Bridges in graph](https://upload.wikimedia.org/wikipedia/commons/d/df/Graph_cut_edges.svg)
